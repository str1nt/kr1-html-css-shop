# TechStore

Учебный магазин электроники по дисциплине «Фронтенд и бэкенд разработка».
Проект развивается последовательно в практических работах №1–6.

## Структура проекта

- `index.html` — стартовая страница;
- `css/style.css` — внешние стили;
- `images/` — изображения (пока содержит `.gitkeep`, чтобы Git сохранил папку);
- `.gitignore` — исключения из Git;
- `README.md` — описание проекта.

## Технологии

HTML, CSS, Git, GitHub. Для просмотра достаточно открыть `index.html` в браузере.
