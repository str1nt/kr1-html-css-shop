# TechStore

Учебный магазин электроники по дисциплине «Фронтенд и бэкенд разработка».
Выполнены шесть последовательных практических работ на обычных HTML, CSS и JavaScript.

**[Открыть сайт GitHub Pages](https://str1nt.github.io/kr1-html-css-shop/)**

## Страницы и возможности

- `index.html` — главная страница с преимуществами и популярными товарами;
- `catalog.html` — шесть моделей и боковой макет фильтров;
- `contacts.html` — демонстрационные контакты;
- форма заявки в `dialog` на главной и в каталоге;
- проверка обязательных полей, e-mail и формата телефона;
- общая навигация, якоря и хлебные крошки;
- CSS-переменные, состояния, Flexbox и Grid.

Названия моделей, цены, характеристики и контакты демонстрационные.
Форма проверяет данные только в браузере: ничего не отправляет и не сохраняет.
Корзины и оплаты нет. Фильтры — явно обозначенный макет, кнопка применения отключена.

## Как запустить

Скачайте репозиторий или выполните:

```bash
git clone https://github.com/str1nt/kr1-html-css-shop.git
cd kr1-html-css-shop
```

Откройте папку в VS Code, затем `index.html` в браузере.
Зависимостей, сборщика и сервера нет. При просмотре онлайн после обновлений
при необходимости используйте Ctrl+F5, чтобы обновить кэш браузера.

## Проверка формы

Нажмите «Заказать». Имя должно содержать минимум два символа.
Имя, e-mail, телефон, тема и согласие обязательны; дата и комментарий необязательны.
Телефон вводится в формате `+7 (900) 000-00-00`.
Сначала проверьте пустые и ошибочные поля, затем корректное заполнение.
При успехе появится учебное сообщение, окно закроется и поля очистятся.
Esc и кнопка «Закрыть» закрывают окно без отправки.

## CSS и навигация

Повторяющиеся значения объявлены в `:root` и используются через `var()`.
Есть `:hover`, `:focus`, `:focus-visible`, `:disabled`, `:target` и оформление `aria-invalid`.
Меню и внутренняя структура карточек используют Flexbox; сетки товаров и области
`filters` / `products` — CSS Grid. Между элементами задан `gap`.

У каждой страницы свой `title` и `meta description`. Пути относительные.
Меню ведёт к трём страницам и разделам главной `#advantages`, `#popular`, `#contacts`.
На внутренних страницах есть хлебные крошки.
Полная адаптивная вёрстка и БЭМ относятся к следующим практическим занятиям.
