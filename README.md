# TechStore

Учебный магазин электроники по дисциплине «Фронтенд и бэкенд разработка».
Проект развивается последовательно в практических работах №1–6.

## Структура проекта

- `index.html` — стартовая страница;
- `css/style.css` — внешние стили;
- `images/` — изображения (пока содержит `.gitkeep`, чтобы Git сохранил папку);
- `.gitignore` — исключения из Git;
- `README.md` — описание проекта.

## Технологии

HTML, CSS, Git, GitHub. Для просмотра достаточно открыть `index.html` в браузере.

## Постановка контрольной работы №1

Тема: «HTML и CSS: разработка многостраничного сайта».
Нужно разработать сайт интернет-магазина или каталога услуг с главной страницей,
каталогом, карточкой товара, страницей оформления заявки и контактами.
Предусмотрены семантическая разметка, внешний CSS, навигация и оформление основных блоков.
Это постановка будущей контрольной: на этапе практической №2 реализована главная страница.

## Учебные данные

Названия моделей, характеристики и цены демонстрационные. SVG-иллюстрации находятся
в `images/` и не требуют внешних сервисов. Реальные покупки на сайте не совершаются.
