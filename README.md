# TechStore

Учебный магазин электроники по дисциплине «Фронтенд и бэкенд разработка».
Проект развивается последовательно в практических работах №1–6.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог шести моделей;
- `contacts.html` — демонстрационные контакты;
- `css/style.css` — внешние стили;
- `js/main.js` — открытие окна и проверка формы;
- `images/` — локальные SVG-иллюстрации товаров;
- `.gitignore` — исключения из Git;
- `README.md` — описание проекта.

## Технологии

HTML, CSS, базовый JavaScript, Git, GitHub. Для просмотра достаточно открыть `index.html` в браузере.

## Учебные данные

Названия моделей, характеристики и цены демонстрационные. SVG-иллюстрации находятся
в `images/` и не требуют внешних сервисов. Реальные покупки на сайте не совершаются.

## Форма заявки

Нажмите «Заказать» в карточке. Телефон вводится в формате `+7 (900) 000-00-00`.
Имя, e-mail, телефон, тема и согласие обязательны; дата и комментарий необязательны.
При успехе появляется сообщение, форма очищается и окно закрывается.
Серверной части нет: данные не передаются и не сохраняются, заказ не создаётся.

## Организация CSS

В начале `css/style.css` объявлены цвета, отступы, скругления и ширина контейнера
в `:root`. Компоненты используют `var()`. Файл разделён комментариями на смысловые части.
Ссылки, кнопки, карточки и поля имеют `:hover`, поля — `:focus`, клавиатурный фокус
обозначен через `:focus-visible`. Для отключённых кнопок задан `:disabled`,
а для ошибочных полей — `[aria-invalid="true"]`.

## Страницы и переходы

Все страницы используют одну шапку, меню и подвал. Внутренние страницы имеют хлебные крошки.
Меню ведёт к `index.html`, `catalog.html`, `contacts.html` и разделам главной
`index.html#advantages`, `index.html#popular`, `index.html#contacts`.
Для якорей добавлены плавная прокрутка и выделение `:target`.
Все пути относительные и работают внутри адреса проекта GitHub Pages.

## Раскладка

Меню и шапка используют Flexbox. Карточки используют вертикальный Flexbox,
а их кнопки прижаты вниз через `margin-top: auto`. Сетки товаров используют
Grid с тремя колонками. Каталог разбит на области `filters` и `products`
через `grid-template-areas` и `grid-area`, между элементами задан `gap`.

Фильтры — учебный макет: отбора товаров нет, кнопка «Применить» отключена
и показывает состояние `:disabled`. Полная адаптивная вёрстка и БЭМ
относятся к следующим занятиям и в эти шесть работ не входят.
